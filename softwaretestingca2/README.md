# Software Testing Lab Experiments 9–14

This repository contains source files, setup instructions, commands, and execution steps for Experiments 9 through 14.

| Experiment | Topic | Folder |
|---|---|---|
| 9 | Cross-browser automation using Selenium WebDriver | `Experiment-09-Selenium` |
| 10 | Selenium integration with JUnit | `Experiment-10-JUnit` |
| 11 | Bug reporting and tracking with Bugzilla or MantisBT | `Experiment-11-Bug-Tracking` |
| 12 | Test case execution and defect tracking | `Experiment-12-Test-Execution` |
| 13 | Performance testing using Apache JMeter | `Experiment-13-JMeter` |
| 14 | Test plans, test suites, and test summary reports | `Experiment-14-Test-Documentation` |

Read each experiment's README for prerequisites, setup, commands, execution steps, and expected results.

**Lab-sheet note:** Experiment 9 is titled Selenium Grid, but its supplied program launches a local ChromeDriver. Experiment 10's sample code uses JUnit 4 annotations and assertions, despite the broader title mentioning JUnit/TestNG. The implementations document these differences.
